# 28 — دریل‌داون دسته + مدیریت دسته‌ها + الگوهای تکرار (UI)

Type: task
Status: open
Blocked by: 25, 26

## Question

سه صفحهٔ مدیریت، همان هویت ۰۷. **الزام: frontend-design**:

- **دریل‌داون تمام‌صفحهٔ دسته** (کلیک کاشی): جمع دسته در ماه + لیست خرج‌هایش + دکمهٔ «افزودن به این دسته» (شیت ثبت ۲۷ با دستهٔ قفل‌شده)؛ در ماه آینده شامل سطرهای پیش‌بینی با بج (از byCategory ترکیبی/preview)؛ برگشت به داشبورد.
- **صفحهٔ دسته‌ها:** افزودن دستهٔ سفارشی با سواچ رنگ؛ **حذفِ غیرفعالِ دستهٔ پُر** با نشان تعداد خرج + میان‌بر «انتقال همهٔ خرج‌ها به…» (انتخاب دستهٔ مقصد → move-expenses — تصمیم ۰۵/۰۶؛ همان مسیر یادگیریِ معمول را شلیک می‌کند چون ویرایش خرج است)؛ سیستمی با توضیح حذف‌نشدنی (تغییر نام آزاد)؛ ترتیب دسته‌ها.
- **صفحهٔ الگوهای تکرار:** فهرست فعال/متوقف؛ افزودن (عنوان، مبلغ، دسته، روز جلالی ۱..۳۱، تاریخ شروع، پایان اختیاری) — ساخت/ویرایش الگو یادگیری می‌سازد (تصمیم ۰۶)؛ توقف/ازسرگیری (`active`)؛ ویرایش؛ لینک «خرج این ماه تولید شد» به خرجِ تولیدشدهٔ همین ماه؛ برای ماه‌های آینده نمایش پیش‌نمایش سطرها با روزِ clamp (خواندن preview از API ۲۵).
- همهٔ mutationها از fetch wrapper ۲۵ (`/api/v1/categories`, `/api/v1/recurring-templates`)؛ خطای 409 حذف پُر نباید به کاربر برسد چون دکمه غیرفعال است — نمایش حالت خالی/خطا طبق هویت.

## Test plan

- component (jsdom + RTL): غیرفعالی حذف دستهٔ پُر + شمارنده، جریان «انتقال همه به…»، toggle فعال/متوقف الگو؛ دریل‌داون و صفحات با E2E در ۳۰.
- خروجی دیداری: اسکرین‌شات سه صفحه در کامنت تیکت برای تأیید کاربر.
