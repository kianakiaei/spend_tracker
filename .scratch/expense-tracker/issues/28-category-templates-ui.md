## Question

سه صفحهٔ مدیریت، همان هویت ۰۷. **الزام: frontend-design**:

- **دریل‌داون تمام‌صفحهٔ دسته** (کلیک کاشی): جمع دسته در ماه + لیست خرج‌هایش + دکمهٔ «افزودن به این دسته» (شیت ثبت ۲۷ با دستهٔ قفل‌شده)؛ در ماه آینده شامل سطرهای پیش‌بینی با بج (از byCategory ترکیبی/preview)؛ برگشت به داشبورد.
- **صفحهٔ دسته‌ها:** افزودن دستهٔ سفارشی با سواچ رنگ؛ **حذفِ غیرفعالِ دستهٔ پُر** با نشان تعداد خرج + میان‌بر «انتقال همهٔ خرج‌ها به…» (انتخاب دستهٔ مقصد → move-expenses — تصمیم ۰۵/۰۶؛ همان مسیر یادگیریِ معمول را شلیک می‌کند چون ویرایش خرج است)؛ سیستمی با توضیح حذف‌نشدنی (تغییر نام آزاد)؛ ترتیب دسته‌ها.
- **صفحهٔ الگوهای تکرار:** فهرست فعال/متوقف؛ افزودن (عنوان، مبلغ، دسته، روز جلالی ۱..۳۱، تاریخ شروع، پایان اختیاری) — ساخت/ویرایش الگو یادگیری می‌سازد (تصمیم ۰۶)؛ توقف/ازسرگیری (`active`)؛ ویرایش؛ لینک «خرج این ماه تولید شد» به خرجِ تولیدشدهٔ همین ماه؛ برای ماه‌های آینده نمایش پیش‌نمایش سطرها با روزِ clamp (خواندن preview از API ۲۵).
- همهٔ mutationها از fetch wrapper ۲۵ (`/api/v1/categories`, `/api/v1/recurring-templates`)؛ خطای 409 حذف پُر نباید به کاربر برسد چون دکمه غیرفعال است — نمایش حالت خالی/خطا طبق هویت.

## Comments

- 2026-09-09 — **رزول شد: هر سه صفحه سبز — ۳۱۹ پاس، lint/tsc/build تمیز** — با مهارت frontend-design، ادامهٔ هویت ۰۷ نسخهٔ ۲ (کاشی → صفحهٔ هم‌رنگِ خودِ دسته، آناتومی خط‌کشی‌شدهٔ دفتر برای هر دو صفحهٔ مدیریت، شیت ۲۷ برای فرم الگو).
  - **دریل‌داون `/categories/[id]`:** هدر با تینت ۸۵٪ رنگ خود دسته + جمع ماه (ماه آینده = ثبت‌شده + پیش‌بینی با یادداشت، بدون نقل مبلغ کل ماه)؛ CTA خط‌چین «افزودن به این دسته» = شیت ثبتِ **دستهٔ قفل‌شده** (نیمهٔ سپرده‌شدهٔ ۲۷: بدون picker و بدون بج، موتور ساکت، زیرنویس «ثبت در قسط — …»)؛ ردیف خرج → شیت ویرایش، ردیف پیش‌بینی → ویرایش الگو (لینک عمیق). `?month=` بی‌کران مثل داشبورد؛ id نامعتبر/غیر → 404. آناتومی سطرها از دفتر جدا شد (`expense-rows.tsx`) و هر دو مصرفش می‌کنند.
  - **صفحهٔ دسته‌ها:** افزودن با سواچ ۸رنگ (رادیو با نام فارسی)؛ تغییر نام آزاد (سیستمی هم)؛ **ترتیب با پیکان‌های ↑↓** — جابه‌جایی order با دو PATCH، تعویض محلی فقط بعد از موفقیت هر دو (خطا هرگز دروغ نمی‌گوید)؛ گارد حذف: پُرِ خرج = حذف غیرفعال + «n خرج» + میان‌بر «انتقال همهٔ خرج‌ها» (picker مقصد → move-expenses → حذف دستهٔ خالی‌شده — تصمیم ۰۵)؛ **دستهٔ دارای الگو = حذف غیرفعال بدون میان‌بر** (move-expenses فقط خرج را می‌برد؛ 409 بعد از انتقال غیرممکن شد — تفسیر ثبت‌شده)؛ سیستمی فقط «دستهٔ سیستمی» + ویرایش. شمارنده‌ها از دو خواندن GROUP BY تازه: `expenseService.countByCategory` و `recurringService.countByCategory` (الگوهای متوقف هم می‌شمارند چون واقعاً گارد می‌گیرند).
  - **صفحهٔ الگوها:** ردیف‌ها با ریتم «مبلغ · هر ماه، روز n · تا ماه» + بج «متوقف»؛ توقف/ازسرگیری با update فعال؛ **«خرج این ماه تولید شد» → `/?month&expense=`** و داشبورد شیت ویرایش همان خرج را باز می‌کند و پارامتر را می‌شوید؛ پیش‌نمایش سه ماه آینده با روز clamp و بج، زیر برچسب ماه جلالی؛ شیت ثبت/ویرایش الگو = آناتومی ۲۷ (مبلغ نرم + نمایش زنده، روز ۱..۳۱ با پیش‌فرض امروز جلالی، شروع = امروز، پایان اختیاری با چیپ «بدون پایان»، دسته با چیپ). یادگیری روی ساخت/ویرایش سمت سرور (تصمیم ۰۶).
  - **از code-review اعمال شد:** ترتیب دسته‌ها پیاده شد (نیمه‌کاره مانده بود)، لینک خرج تولیدشده واقعاً به خود خرج می‌رود، سطر پیش‌بینی به ویرایش همان الگو (`/templates?edit=`، یک‌بار و خودپاک‌شونده)، زیرنویس دریل‌داون دیگر کل پیش‌بینی ماه را زیر جمع دسته نمی‌آورد، اشتراکِ ui/style + ui/use-run + ui/client-row + categoryColorMap به‌جای کپی‌ها، حذف non-null assertion، غلط «منتقال».
