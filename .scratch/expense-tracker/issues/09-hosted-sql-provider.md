## Question

کاربر یک سرویس SQL با «اکانت آنلاین رایگان» خواسته (چرخش استک 2026-09-06). برای این اپ — Next.js تمام‌استک، Drizzle، یک کاربر به‌ازای هر حساب، حجم دادهٔ ناچیز، احتمالاً دیپلوی روی Vercel یا مشابه — کدام سرویس درست است؟

- مقایسهٔ واقعی پلن‌های رایگان در 2026-09 فقط با منابع رسمی: Neon، Supabase، Turso (libSQL)، Cloudflare D1، Xata، PlanetScale، Vercel Postgres و هر گزینهٔ معتبر دیگر. آیا «رایگانِ همیشگی» (نه trial) هنوز وجود دارد؟ سقف‌ها: حجم/ردیف، compute و sleep خودکار، اتصال هم‌زمان، بکاپ.
- سازگاری با Drizzle و Next.js: نوع درایور (HTTP/serverless در برابر TCP)، جریان migration، دیتابیس دوم برای تست (branching؟).
- ریسک‌های عملی برای کاربر در ایران: محدودیت ثبت‌نام/پرداخت (فقط مستند رسمی یا گزارش تأییدشده — به‌عنوان ریسک ثبت شود)، ریسک بسته‌شدن حساب، نزدیک‌ترین ریجن و تأخیر، مسیر اکسپورت/مهاجرت برای رهایی از قفل‌شدگی.
- خروجی: توصیهٔ نهایی (سرویس اول + جایگزین) با جدول مقایسهٔ دقیق و rationale.
