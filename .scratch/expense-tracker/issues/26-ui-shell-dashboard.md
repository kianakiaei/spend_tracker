# 26 — پوستهٔ UI + داشبورد ماه از پروتوتایپ v2 (RSC)

Type: task
Status: open
Blocked by: 24

## Question

داشبورد خوانش‌محور، از نو و درست ساخته شود (کدِ پروتوتایپ الگوی تولید نیست — تصریح تیکت ۰۷). **الزام نقشه: سشن UI از مهارت frontend-design**:

- توکن‌های تأییدشدهٔ ۰۷: کاغذ `#FAFAF7`، جوهر `#20241F`، اکسنت یشمی واحد `#1A7A5C`، خط‌کشی `#E7E5DD`؛ **Vazirmatn سلف‌هاست** (woff2 در ریپو — fetch فونت هنگام build از ایران ریسک دارد)؛ وزن ۸۰۰ برای جمع ماه؛ RTL کامل؛ ارقام فارسی با `fa-IR` (از ماژول ۲۰)؛ مینیمال — بدون نوار انباشته، بدون رنگ اضافه.
- پوسته: لِی‌اوت پایهٔ RTL + هدر (جای ایمیل/خروج با ۲۹ می‌آید؛ فعلاً خالی) + ناوبری ماه **بدون سقف** (گذشته/آینده/جاری — فلش‌ها + برچسب جلالی از ماژول ۲۰؛ `searchParams` ناهمگام Next 16 با `?month=1405-06`).
- داشبورد = RSC که **مستقیم از سرویس‌ها** می‌خواند (getSummary + listByMonth — هرگز handler را fetch نمی‌کند): جمع ماه بزرگ در بالا (+ زیرنویس «شامل پیش‌بینی الگوها: X تومان» فقط برای ماه آینده از `forecastToman`) → شبکهٔ **کاشی‌های متناسب با سهم** هر دسته (تینت ملایم از رنگ دسته + نقطهٔ رنگی؛ کاشیِ بزرگ‌ترین چهارسوتنی دوردیفه؛ نسبت از byCategory) → زیر شبکه، **لیست دفتری** خرج‌های ماه با خط‌کشی (روز، عنوان + نقطهٔ دسته، «از الگو» برای sourceRecurringId، مبلغ؛ چیپ «بدون تاریخ» بالای لیست؛ در ماه آینده سطرهای پیش‌بینی با بج «پیش‌بینی» و روزِ clamp شده).
- تعامل‌ها در همین تیکت فقط خوانش‌اند: کلیک کاشی → مسیر دریل‌داون (صفحه با ۲۸؛ لینک فعلاً به همان مسیر)؛ کلیک سطر پیش‌بینی → صفحهٔ الگوها (۲۸)؛ کلیک سطر خرج → شیت ویرایش (۲۷ — فعلاً بی‌عمل).
- دسته‌های بی‌خرج در ماه آینده با فقط-پیش‌بینی هم کاشی می‌گیرند (از byCategory ترکیبی سرویس ۲۴).

- خروجی دیداری: داشبورد سه حالت (جاری/گذشته/آینده) روی دادهٔ dev با اسکرین‌شات در کامنت تیکت برای تأیید کاربر.
