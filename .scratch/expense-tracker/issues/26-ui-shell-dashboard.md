- داشبورد = RSC که **مستقیم از سرویس‌ها** می‌خواند (getSummary + listByMonth — هرگز handler را fetch نمی‌کند): جمع ماه بزرگ در بالا (+ زیرنویس «شامل پیش‌بینی الگوها: X تومان» فقط برای ماه آینده از `forecastToman`) → شبکهٔ **کاشی‌های متناسب با سهم** هر دسته (تینت ملایم از رنگ دسته + نقطهٔ رنگی؛ کاشیِ بزرگ‌ترین چهارسوتنی دوردیفه؛ نسبت از byCategory) → زیر شبکه، **لیست دفتری** خرج‌های ماه با خط‌کشی (روز، عنوان + نقطهٔ دسته، «از الگو» برای sourceRecurringId، مبلغ؛ چیپ «بدون تاریخ» بالای لیست؛ در ماه آینده سطرهای پیش‌بینی با بج «پیش‌بینی» و روزِ clamp شده).
